# 📝 To-Do List

A simple To-Do List web application built using HTML, CSS and JavaScript.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Clean and simple UI
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

While building this project, I practiced:

- DOM manipulation
- Event handling
- Working with user input
- JavaScript logic
- Creating dynamic elements using JavaScript
